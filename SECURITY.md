# Security policy

## Supported versions

Security fixes are applied to the latest published minor release. Users should
upgrade to the latest `0.x` release before reporting a vulnerability.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting or a private security advisory:

<https://github.com/suatkeskin/scanner_bridge/security/advisories/new>

Include the affected version, platform, a minimal reproduction, and the impact
you observed. Remove credentials, tokens, device identifiers and personal data
from all reports and attachments.

We will acknowledge a report as soon as practical, investigate it privately,
and coordinate disclosure and a fix with the reporter.
